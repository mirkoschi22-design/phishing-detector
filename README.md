\# 🎣 Phishing Detector



Detector de URLs de phishing hecho en Python. Analiza patrones sospechosos para prevenir estafas.



\*\*Autor:\*\* Mirko David Schiavi - Roldán, Santa Fe, Argentina 🇦🇷

\*\*Portfolio:\*\* https://mirkoschi22-design.github.io



\### 🚀 Características

\- Detecta IPs en lugar de dominios

\- Detecta acortadores (bit.ly, tinyurl) y @ en URLs

\- Analiza palabras engañosas (login, verify, secure, bank)

\- Sistema de puntaje de riesgo (BAJO/MEDIO/ALTO)

\- 100% Python, sin dependencias



\### 💻 Uso

```bash

python phishing\_detector.py
